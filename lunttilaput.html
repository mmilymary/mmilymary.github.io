    Muuttujat, tyypit ja teksti

    Muuttuja on nimilappu arvolle. Pythonissa ei kerrota tyyppiä etukäteen, se päättelee sen itse.

    Neljä perustyyppiä riittää pitkälle: kokonaisluku, desimaaliluku, teksti ja totuusarvo. type() kertoo, mikä on mitäkin. F-merkkijonolla saat muuttujat suoraan tekstin sisään.

    nimi = "Ada"          # str  (teksti)
ika = 20              # int  (kokonaisluku)
pituus = 1.68         # float (desimaali, piste eikä pilkku!)
opiskelee = True      # bool (True / False)

print(type(ika))                   # <class 'int'>
print(f"Moi {nimi}, olet {ika}!")  # Moi Ada, olet 20!
print("a", "b", sep="-")           # a-b

    7 / 2     # 3.5  tavallinen jako, tulos aina float
7 // 2    # 3    kokonaisjako (pyöristää alaspäin)
7 % 2     # 1    jakojäännös, kätevä parillisuuteen
2 ** 3    # 8    potenssi

    Indeksit alkaa nollasta. Negatiivinen indeksi laskee lopusta. Viipale [1:4] ottaa kohdat 1, 2 ja 3, eli loppupää jää pois.

sana[0]       # 'k'
sana[-1]      # 'e'

"-".join(["a", "b"])  # 'a-b'

    Viikko 2 · ti 6.10.if · while · for · range

    Valinta ja toisto

    If päättää, tehdäänkö jotain. While ja for päättää, kuinka monta kertaa.

    Sisennys (neljä välilyöntiä) ei ole koristetta. Pythonissa se on lohkon raja. Ehtoja tarkistetaan ylhäältä alas ja ensimmäinen tosi voittaa.

    pisteet = 72
if pisteet >= 90:
    print("Kiitettävä")
elif pisteet >= 50:
    print("Hyväksytty")    # ← tämä tulostuu
else:
    print("Hylätty")

    range

    Muoto on range(alku, loppu, askel). Loppu ei tule mukaan. Koskaan.

    list(range(5))          # [0, 1, 2, 3, 4]
list(range(2, 6))       # [2, 3, 4, 5]
list(range(10, 0, -3))  # [10, 7, 4, 1]

    for vs. while

    For, kun tiedät mitä käydään läpi. While, kun toistetaan niin kauan kuin joku ehto on voimassa.

    for i in range(3):
    print(i)        # 0, 1, 2

n = 3
while n > 0:
    print(n)        # 3, 2, 1
    n -= 1          # unohda tämä, niin silmukka ei lopu ikinä

for i in range(10):
    if i == 2:
        continue    # hyppää tämän kierroksen yli
    if i == 5:
        break       # lopettaa koko silmukan
    print(i)        # 0, 1, 3, 4
    Sudenkuoppa

    = asettaa arvon, == vertaa. if x = 5: on syntaksivirhe, if x == 5: on se mitä tarkoitit.

    Funktiot

    Funktio on resepti: annat ainekset (parametrit), se antaa takaisin valmiin (return).

    def tervehdi(nimi: str, huuto: bool = False) -> str:

    Viikko 8 · ti 24.11.Luokat · oliot · metodit

    Olio-ohjelmointi

    Luokka on muotti, olio on siitä valettu kappale. self tarkoittaa "tämä nimenomainen kappale".

    class Kurssi:
    def __init__(self, nimi: str, op: int):   # ajetaan kun olio luodaan
        self.nimi = nimi                      # tietojäsenet
        self.op = op
        self.valmis = False

    def suorita(self):                        # metodi
        self.valmis = True

    def __str__(self):                        # mitä print näyttää
        tila = "valmis" if self.valmis else "kesken"
        return f"{self.nimi} ({self.op} op, {tila})"

    @classmethod
    def tekstista(cls, rivi: str):            # luokkametodi: saa luokan, ei oliota
        nimi, op = rivi.split(";")
        return cls(nimi, int(op))

python = Kurssi("Python", 5)
python.suorita()
print(python)                          # Python (5 op, valmis)
print(Kurssi.tekstista("Tietoverkot;5"))  # Tietoverkot (5 op, kesken)
    Sudenkuoppa

    Jokainen metodi tarvitsee self-parametrin ensimmäiseksi. Ja self.nimi on olion tieto, pelkkä nimi on vain paikallinen muuttuja, joka katoaa funktion lopussa.

    Harjoitus 8

    Tee luokka Tili, jolla on talleta(summa), nosta(summa) ja saldo. Nosto ei saa viedä saldoa miinukselle, vaan palauttaa silloin False.

    Näytä vihje

    Tarkista ensin, riittääkö saldo. Vähennä vasta sen jälkeen.

    Näytä ratkaisu
    class Tili:
    def __init__(self, omistaja: str):
        self.omistaja = omistaja
        self.saldo = 0

    def talleta(self, summa: float):
        self.saldo += summa

    def nosta(self, summa: float) -> bool:
        if summa > self.saldo:
            return False
        self.saldo -= summa
        return True

tili = Tili("Ada")
tili.talleta(50)
print(tili.nosta(80))   # False
print(tili.nosta(20))   # True
print(tili.saldo)       # 30

    Verkko ja JSON

    JSON on tekstiä, joka näyttää sanakirjalta. json.loads tekee siitä oikean sanakirjan, json.dumps takaisin tekstiksi.

    import json

data = json.loads('{"nimi": "Ada", "op": 20}')   # str → dict
data["op"]                                         # 20
json.dumps(data)                                   # dict → str
json.dumps({"kieli": "ä"}, ensure_ascii=False)     # '{"kieli": "ä"}'

      Ensimmäiset kyselyt

      Osa 2 · to 8.10.ORDER BY · LIMIT · DISTINCT · AS

      Taulut ja kyselyt

      Tietokanta palauttaa rivit missä järjestyksessä sattuu. Jos järjestyksellä on väliä, se pitää pyytää ORDER BY:llä.

      Järjestys ja määrä

      SELECT nimi, vuosi FROM kirja ORDER BY vuosi LIMIT 3;
-- Frankenstein                    1818
-- Arthur Gordon Pymin seikkailut  1838
-- Usherin talon häviö             1839

SELECT nimi, sivut FROM kirja ORDER BY sivut DESC LIMIT 2;   -- DESC = suurin ensin
-- Dracula         488
-- Humiseva harju  416

      Ei toistoja

      SELECT DISTINCT maa FROM kirjailija;
-- Iso-Britannia
-- Yhdysvallat
-- Irlanti

      Laskut ja uudet nimet

      Sarakkeilla voi laskea, ja AS antaa tulokselle nimen. Nimeä voi käyttää ORDER BY:ssä.

      SELECT nimi, round(hinta * 0.9, 2) AS ale
FROM kirja
ORDER BY ale DESC
LIMIT 3;
-- Dracula             21.6
-- Kalevala            19.8
-- Hulluuden vuorilla  17.55
      Sudenkuoppa

      Kahden kokonaisluvun jako antaa kokonaisluvun. Desimaalit saa, kun toinen luku on desimaaliluku.

      SELECT 7 / 2, 7 / 2.0, 7 % 2;
-- 3   3.5   1

      Osa 3 · to 22.10.WHERE · AND/OR · IN · BETWEEN · LIKE · NULL

      Ehdot ja tyhjät arvot

      WHERE päättää, mitkä rivit pääsevät tulokseen. NULL tarkoittaa, ettei arvoa tiedetä, eikä sitä voi verrata yhtäsuuruusmerkillä.

      SELECT nimi FROM kirja WHERE vuosi < 1840;
-- Frankenstein, Usherin talon häviö, Arthur Gordon Pymin seikkailut

SELECT nimi, vuosi FROM kirja
WHERE vuosi BETWEEN 1840 AND 1850       -- molemmat päät mukana
ORDER BY vuosi;
-- Korppi 1845, Humiseva harju 1847, Kalevala 1849

SELECT nimi FROM kirja WHERE kirjailija_id IN (2, 3);   -- Poe ja Lovecraft
-- Usherin talon häviö, Cthulhun kutsu, Korppi, Hulluuden vuorilla,
-- Arthur Gordon Pymin seikkailut

      AND ja OR

      SELECT nimi FROM kirja WHERE sivut > 200 AND hinta < 20;
-- Humiseva harju, Frankenstein

SELECT nimi FROM kirja WHERE vuosi < 1840 OR sivut > 400;
-- Humiseva harju, Frankenstein, Dracula, Usherin talon häviö,
-- Arthur Gordon Pymin seikkailut

      Arthur Gordon Pymin seikkailut (256 sivua) puuttuu ensimmäisestä tuloksesta, koska sen hinta on NULL. NULL ei ole pienempi eikä suurempi kuin 20, joten ehto ei ole tosi.

      LIKE

      % tarkoittaa mitä tahansa määrää merkkejä ja _ tasan yhtä merkkiä.

      SELECT nimi FROM kirja WHERE nimi LIKE 'H%';
-- Humiseva harju, Hulluuden vuorilla

SELECT nimi FROM kirja WHERE nimi LIKE '%talo%';
-- Usherin talon häviö

      NULL

      SELECT nimi FROM kirja WHERE hinta IS NULL;
-- Korppi, Arthur Gordon Pymin seikkailut

SELECT nimi, IFNULL(hinta, 'ei tiedossa') FROM kirja WHERE id IN (5, 6);
-- Cthulhun kutsu  11.9
-- Korppi          ei tiedossa
      Sudenkuoppa

      WHERE hinta = NULL ei anna virhettä, mutta ei myöskään yhtään riviä. Käytä aina IS NULL tai IS NOT NULL.

      LIKE ei välitä isoista ja pienistä kirjaimista, mutta vain a–z-kirjaimilla. Ä ja ö lasketaan eri merkeiksi isona ja pienenä: 'Ä' LIKE 'ä' on epätosi.

      Harjoitus 3

      Hae 1800-luvulla julkaistut kirjat, joiden hinta on tiedossa. Näytä nimi, vuosi ja hinta vanhimmasta uusimpaan.

      Näytä vihje

      Kaksi ehtoa AND:lla: vuosi väliltä 1800–1899 ja hinta, joka ei ole NULL.

      Näytä ratkaisu
      SELECT nimi, vuosi, hinta
FROM kirja
WHERE vuosi BETWEEN 1800 AND 1899
  AND hinta IS NOT NULL
ORDER BY vuosi;
-- Frankenstein         1818  12.5
-- Usherin talon häviö  1839  8.5
-- Humiseva harju       1847  16.9
-- Kalevala             1849  22.0
-- Dracula              1897  24.0
      Osa 4 · to 29.10.INSERT · UPDATE · DELETE

      Lisää, muuta ja poista

      INSERT lisää rivin, UPDATE muuttaa rivejä ja DELETE poistaa niitä. Kaksi viimeistä tarvitsevat lähes aina WHERE-ehdon.

      INSERT INTO kirja (nimi, kirjailija_id, vuosi, sivut, hinta)
VALUES ('Charles Dexter Wardin tapaus', 3, 1941, 144, 14.90);
-- id jätettiin pois, joten SQLite antoi suurinta id:tä seuraavan numeron: 10

UPDATE kirja SET hinta = 9.90 WHERE nimi = 'Korppi';

UPDATE kirja SET hinta = round(hinta * 1.1, 2) WHERE kirjailija_id = 3;
-- Lovecraftin kirjat kallistuvat 10 %:
-- Cthulhun kutsu 11.9 → 13.09, Hulluuden vuorilla 19.5 → 21.45,
-- Charles Dexter Wardin tapaus 14.9 → 16.39

DELETE FROM lainaus WHERE palautettu IS NOT NULL;
-- poistaa palautetut lainat, jäljelle jää 3 riviä
      Sudenkuoppa

      Ilman WHERE-ehtoa UPDATE muuttaa ja DELETE poistaa kaikki rivit, eikä SQLite kysy varmistusta. Aja sama ehto ensin SELECT-kyselynä ja katso, mitkä rivit se löytää.

      SELECT * FROM lainaus WHERE palautettu IS NOT NULL;   -- 1. tarkista
DELETE   FROM lainaus WHERE palautettu IS NOT NULL;   -- 2. poista
      Harjoitus 4

      Lisää Mary Shelleylle kirja Viimeinen ihminen (1826, 480 sivua, hinta ei tiedossa). Merkitse sitten Gracen Dracula-laina palautetuksi 1.10.2026.

      Näytä vihje

      Mary Shelleyn id on 1. Hinnan voi jättää pois sarakelistasta, jolloin siihen tulee NULL. Päivämäärät ovat muodossa '2026-10-01'.

      Näytä ratkaisu
      INSERT INTO kirja (nimi, kirjailija_id, vuosi, sivut)
VALUES ('Viimeinen ihminen', 1, 1826, 480);

UPDATE lainaus
SET palautettu = '2026-10-01'
WHERE lainaaja = 'Grace' AND kirja_id = 3;

SELECT * FROM lainaus WHERE lainaaja = 'Grace';
-- 4  5  Grace  2026-09-18  NULL
-- 5  3  Grace  2026-09-25  2026-10-01
      Osa 5 · to 5.11.JOIN · LEFT JOIN · aliakset

      Taulujen liitokset

      JOIN yhdistää kaksi taulua sarakkeen kautta, joka on molemmissa. Kirjassa on kirjailija_id, ja se vastaa kirjailijataulun id:tä.

      SELECT kirja.nimi, kirjailija.nimi
FROM kirja
JOIN kirjailija ON kirja.kirjailija_id = kirjailija.id
ORDER BY kirja.vuosi
LIMIT 3;
-- Frankenstein                    Mary Shelley
-- Arthur Gordon Pymin seikkailut  Edgar Allan Poe
-- Usherin talon häviö             Edgar Allan Poe

      Lyhyet aliakset (k, a, l) säästävät kirjoittamista, kun tauluja on monta.

      SELECT l.lainaaja, k.nimi
FROM lainaus l
JOIN kirja k ON l.kirja_id = k.id
WHERE l.palautettu IS NULL
ORDER BY l.lainaaja;
-- Ada    Frankenstein
-- Grace  Cthulhun kutsu
-- Grace  Dracula

      LEFT JOIN

      Tavallinen JOIN pudottaa rivit, joille ei löydy paria. Kalevalalla ei ole kirjailijaa, joten liitoksessa on 8 kirjaa eikä 9. LEFT JOIN pitää kaikki vasemman taulun rivit ja täyttää puuttuvat kohdat NULLilla.

      SELECT k.nimi
FROM kirja k
LEFT JOIN lainaus l ON l.kirja_id = k.id
WHERE l.id IS NULL
ORDER BY k.nimi;
-- kirjat, joita ei ole lainattu kertaakaan:
-- Arthur Gordon Pymin seikkailut, Hulluuden vuorilla, Kalevala, Korppi,
-- Usherin talon häviö
      Sudenkuoppa

      Jos LEFT JOINin oikean taulun ehto kirjoitetaan WHERE-osaan, NULL-rivit putoavat pois ja liitos toimii kuin tavallinen JOIN. Ehto kuuluu silloin ON-osaan.

      -- kaikki kirjailijat, ja vuoden 1840 jälkeiset kirjat jos niitä on
SELECT a.nimi, k.nimi
FROM kirjailija a
LEFT JOIN kirja k ON k.kirjailija_id = a.id AND k.vuosi > 1840
ORDER BY a.nimi, k.nimi;
-- Mary Shelley näkyy NULLin kanssa, koska Frankenstein on vuodelta 1818.
-- Siirrä ehto WHEREen, niin hän katoaa kokonaan.
      Harjoitus 5

      Listaa jokaisesta lainasta päivä, lainaaja, kirjan nimi ja kirjailija. Uusin laina ensin.

      Näytä vihje

      Tarvitset kaksi liitosta: lainaus → kirja ja kirja → kirjailija.

      Näytä ratkaisu
      SELECT l.lainattu, l.lainaaja, k.nimi AS kirja, a.nimi AS kirjailija
FROM lainaus l
JOIN kirja k      ON k.id = l.kirja_id
JOIN kirjailija a ON a.id = k.kirjailija_id
ORDER BY l.lainattu DESC;
-- 2026-09-25  Grace  Dracula         Bram Stoker
-- 2026-09-18  Grace  Cthulhun kutsu  H. P. Lovecraft
-- 2026-09-15  Ada    Frankenstein    Mary Shelley
-- 2026-09-10  Linus  Humiseva harju  Emily Brontë
-- 2026-09-01  Ada    Dracula         Bram Stoker

      Osa 7 · to 19.11.VIEW · INDEX · EXPLAIN QUERY PLAN

      Näkymät ja indeksit

      Näkymä on tallennettu kysely, jota käytetään kuin taulua. Indeksi on hakemisto, joka nopeuttaa hakuja isoissa tauluissa.

      Näkymä

      CREATE VIEW lainassa AS
SELECT l.lainaaja, k.nimi, l.lainattu
FROM lainaus l
JOIN kirja k ON k.id = l.kirja_id
WHERE l.palautettu IS NULL;

SELECT * FROM lainassa ORDER BY lainattu;
-- Ada    Frankenstein    2026-09-15
-- Grace  Cthulhun kutsu  2026-09-18
-- Grace  Dracula         2026-09-25

      Näkymä ei tallenna tietoa, vaan ajaa kyselyn joka kerta uudelleen. Kun lainaus palautetaan, se katoaa näkymästä itsestään.

      Indeksi

      EXPLAIN QUERY PLAN kertoo, miten SQLite aikoo hakea rivit. SCAN tarkoittaa, että se käy koko taulun läpi. SEARCH ... USING INDEX tarkoittaa, että se hyppää suoraan oikeisiin riveihin.

      EXPLAIN QUERY PLAN SELECT * FROM kirja WHERE vuosi = 1897;
-- SCAN kirja

CREATE INDEX idx_kirja_vuosi ON kirja(vuosi);

EXPLAIN QUERY PLAN SELECT * FROM kirja WHERE vuosi = 1897;
-- SEARCH kirja USING INDEX idx_kirja_vuosi (vuosi=?)
      Sudenkuoppa

      Indeksi ei ole ilmainen. Se vie tilaa, ja jokainen INSERT ja UPDATE joutuu päivittämään myös indeksin. Indeksoi sarakkeet, joilla oikeasti haetaan tai liitetään.

      Harjoitus 7

      Tee näkymä hinnasto, jossa on kirjan nimi ja hinta. Kirjat ilman hintaa jätetään pois. Hae näkymästä kolme kalleinta.

      Näytä vihje

      Rajaus tulee näkymän sisälle, järjestys ja LIMIT vasta kyselyyn, joka hakee näkymästä.

      Näytä ratkaisu
      CREATE VIEW hinnasto AS
SELECT nimi, hinta FROM kirja WHERE hinta IS NOT NULL;

SELECT * FROM hinnasto ORDER BY hinta DESC LIMIT 3;
-- Dracula             24.0
-- Kalevala            22.0
-- Hulluuden vuorilla  19.5
      Osa 8 · to 26.11.Funktiot · GROUP BY · HAVING · CASE

      SQLiten valmiit funktiot

      Osa funktioista käsittelee yhtä arvoa kerrallaan, kuten upper. Koostefunktiot, kuten COUNT ja AVG, tiivistävät monta riviä yhdeksi luvuksi.

      Teksti ja päivämäärät

      SELECT upper(nimi), length(nimi) FROM kirja WHERE id = 2;   -- FRANKENSTEIN  12
SELECT substr(nimi, 1, 5) FROM kirja WHERE id = 1;          -- Humis
SELECT nimi || ' (' || vuosi || ')' FROM kirja WHERE id = 3; -- Dracula (1897)

SELECT date('2026-10-01', '+14 days');                        -- 2026-10-15
SELECT julianday('2026-10-01') - julianday('2026-09-15');     -- 16.0

      Koostefunktiot

      SELECT COUNT(*), COUNT(hinta) FROM kirja;   -- 9  7   (COUNT(sarake) ohittaa NULLit)

SELECT round(AVG(hinta), 2), MIN(hinta), MAX(hinta), SUM(sivut) FROM kirja;
-- 16.47  8.5  24.0  2208

      GROUP BY ja HAVING

      GROUP BY laskee koosteen erikseen jokaiselle ryhmälle. WHERE rajaa rivejä ennen ryhmittelyä, HAVING ryhmiä sen jälkeen.

      SELECT a.nimi, COUNT(k.id) AS kirjoja, round(AVG(k.sivut)) AS sivuja_keskim
FROM kirjailija a
JOIN kirja k ON k.kirjailija_id = a.id
GROUP BY a.id, a.nimi
HAVING COUNT(k.id) >= 2
ORDER BY a.nimi;
-- Edgar Allan Poe  3  123.0
-- H. P. Lovecraft  2  128.0

      CASE

      SELECT nimi,
  CASE WHEN sivut > 400 THEN 'tiiliskivi'
       WHEN sivut > 150 THEN 'keskikokoinen'
       ELSE 'ohut' END AS koko
FROM kirja ORDER BY sivut DESC LIMIT 4;
-- Dracula         tiiliskivi
-- Humiseva harju  tiiliskivi
-- Kalevala        keskikokoinen
-- Frankenstein    keskikokoinen
      Sudenkuoppa

      Jos sarake on SELECT-osassa mutta ei koostefunktiossa eikä GROUP BY:ssä, SQLite valitsee siihen arvon jostain ryhmän rivistä ilman virheilmoitusta. Esimerkiksi SQL Server ja PostgreSQL antavat tästä virheen, joten kaikki SELECT-osan tavalliset sarakkeet kannattaa kirjoittaa myös GROUP BY:hin.

      Harjoitus 8

      Laske jokaiselle maalle kirjojen määrä ja keskimääräinen sivumäärä kokonaislukuna. Eniten kirjoja ensin.

      Näytä vihje

      Maa on kirjailijataulussa, sivumäärä kirjataulussa. Liitä, ryhmittele maan mukaan ja pyöristä round-funktiolla.

      Näytä ratkaisu
      SELECT a.maa, COUNT(*) AS kirjoja, round(AVG(k.sivut)) AS sivuja
FROM kirja k
JOIN kirjailija a ON a.id = k.kirjailija_id
GROUP BY a.maa
ORDER BY kirjoja DESC;
-- Yhdysvallat    5  125.0
-- Iso-Britannia  2  348.0
-- Irlanti        1  488.0
      Osa 9 · to 3.12.BEGIN · COMMIT · ROLLBACK

      Transaktiot

      Transaktio niputtaa monta muutosta yhdeksi. Joko kaikki onnistuvat, tai mikään ei jää voimaan.

      Tavallinen esimerkki on tilisiirto: rahan pitää lähteä yhdeltä tililtä ja tulla toiselle. Jos jälkimmäinen epäonnistuu, myös ensimmäinen perutaan.

      CREATE TABLE tili (nimi TEXT PRIMARY KEY, saldo INTEGER CHECK (saldo >= 0));
INSERT INTO tili VALUES ('Ada', 100), ('Linus', 20);

BEGIN;
UPDATE tili SET saldo = saldo + 50 WHERE nimi = 'Ada';
UPDATE tili SET saldo = saldo - 50 WHERE nimi = 'Linus';
-- CHECK constraint failed: saldo >= 0
ROLLBACK;

SELECT * FROM tili;
-- Ada    100
-- Linus  20     ← Adankaan saldo ei muuttunut

      Hätäjarru

      ROLLBACK peruu kaikki muutokset takaisin transaktion alkuun, myös vahingossa tehdyt.

      BEGIN;
DELETE FROM lainaus;               -- oho, kaikki lainat lähti
SELECT COUNT(*) FROM lainaus;      -- 0
ROLLBACK;
SELECT COUNT(*) FROM lainaus;      -- 5
      ACIDTarkoittaa
      AtomicityKaikki tai ei mitään.
      ConsistencySäännöt pitävät transaktion jälkeenkin.
      IsolationKeskeneräiset muutokset eivät näy muille.
      DurabilityHyväksytty muutos säilyy, vaikka virta katkeaisi.
      Sudenkuoppa

      Virhe transaktion keskellä ei peru aiempia muutoksia itsestään. Ne jäävät odottamaan, ja jos seuraavaksi annetaan COMMIT, puolikas muutos tallentuu. Virheen jälkeen tulee ROLLBACK.

      Harjoitus 9

      Ada palauttaa Frankensteinin 1.10.2026, ja Linus lainaa sen samana päivänä. Tee molemmat muutokset yhtenä transaktiona.

      Näytä vihje

      Ensin UPDATE vanhaan lainaan (id 2), sitten INSERT uudesta lainasta. Frankensteinin id on 2.

      Näytä ratkaisu

UPDATE lainaus SET palautettu = '2026-10-01' WHERE id = 2;
INSERT INTO lainaus (kirja_id, lainaaja, lainattu) VALUES (2, 'Linus', '2026-10-01');
COMMIT;

SELECT * FROM lainaus WHERE kirja_id = 2;

-- 6  2  Linus  2026-10-01  NULL
